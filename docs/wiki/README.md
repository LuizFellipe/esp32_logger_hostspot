## Escopo

O repositório contém mais de um projeto ESP32. As páginas distinguem o logger local com cartão SD, o protótipo de telemetria celular e experimentos/bibliotecas. O firmware e os READMEs de cada pasta são a fonte para pinos, constantes e comportamento efetivo; esta wiki fornece navegação e visão integrada.
